从这里开始

三步准备。可直接在浏览器中使用，添加到主屏幕是可选项。

01 · Windows x64

电脑本地使用

解压 Windows 离线便携包，在文件夹内双击 Start-WardNote.cmd。无需安装运行环境；保留此文件夹。关闭启动面板不会停止服务。

Start-WardNote.cmd

一键启动 / 停止入口是文件夹内的程序，浏览器帮助页不能代为运行。

02 · HTTPS

手机与平板

请管理员先部署可信 HTTPS 地址，再用手机浏览器打开。个人电脑上的本机地址不能直接发给手机使用。

链接只打开程序，不会传送账号、密码或患者资料。换设备或地址后，请恢复已核验的加密备份；同名账号不会自动同步。

03 · PWA

选择打开方式

iPhone / iPad：在 Safari 中打开，点“分享”→“添加到主屏幕”→“添加”；若显示“作为网页 App 打开”，保持开启。

Android Chrome：打开菜单 ⋮ →“添加到主屏幕”或“安装应用”（若提供），按提示完成。

电脑 Chrome / Edge：在地址栏或浏览器菜单中选择“安装”（若提供）。

没有安装按钮时，可继续在浏览器使用并收藏此地址；安装选项由浏览器决定。

检查离线准备

首次请保持联网，等待程序资源准备完成，再重新打开并检查。检查通过后，先用模拟资料试验断网打开和保存。

通过检查不等于备份。正式使用前，请在自己的设备上验证打开、保存和恢复；实际 PWA 安装及硬件兼容性仍需验证。

Local computer use

Extract the Windows offline portable package and double-click Start-WardNote.cmd in its folder. No runtime installation is needed. Keep this folder; closing the launcher does not stop the service.

Start-WardNote.cmd

Phones and tablets

Ask the deployment owner to prepare a trusted HTTPS address, then open it in the phone browser. A computer localhost address cannot be shared for phone access.

The link only opens the app. It does not transfer accounts, passwords or patient data. Restore a verified encrypted backup on a new device or address; matching account names do not sync.

iPhone / iPad: open in Safari, tap Share → Add to Home Screen → Add. Keep Open as Web App enabled if shown.

Android Chrome: open the ⋮ menu → Add to home screen or Install app, if offered, and follow the prompts.

Desktop Chrome / Edge: choose Install from the address bar or browser menu, if offered.

If there is no install button, keep using the browser and bookmark this address. Installation options depend on the browser.

Check offline preparation

Stay online for the first preparation, wait for app resources, then reopen and check. Once checks pass, use synthetic data to test offline opening and saving.

Passing this check is not a backup. Verify opening, saving and restoring on your own device before real use; actual PWA installation and hardware compatibility still need verification.

Три шага подготовки. Можно работать в браузере; значок на главном экране необязателен.

01 · Windows x64

Локально на компьютере

Распакуйте переносной пакет Windows и дважды щёлкните Start-WardNote.cmd. Установка среды не нужна. Сохраните папку; закрытие панели не останавливает службу.

Start-WardNote.cmd

Программы запуска и остановки открываются из папки; эта справка не запускает их.

02 · HTTPS

Телефоны и планшеты

Администратор должен подготовить доверенный адрес HTTPS. Откройте его в браузере телефона. Адрес localhost компьютера на телефоне не работает.

Ссылка только открывает приложение и не передаёт учётные записи, пароли или данные пациентов. На новом устройстве или адресе восстановите проверенную зашифрованную копию; одинаковые имена учётных записей не обеспечивают синхронизацию.

03 · PWA

Выберите способ открытия

iPhone / iPad: откройте в Safari, нажмите «Поделиться» → «На экран Домой» → «Добавить». Если доступно, оставьте «Открывать как веб-приложение» включённым.

Chrome Android: меню ⋮ → «Добавить на главный экран» или «Установить приложение», если доступно; следуйте подсказкам.

Chrome / Edge на компьютере: выберите «Установить» в адресной строке или меню, если доступно.

Если кнопки установки нет, продолжайте в браузере и сохраните адрес в закладки. Варианты установки зависят от браузера.

Проверьте автономную подготовку

При первой подготовке оставайтесь в сети, дождитесь ресурсов, затем откройте заново и проверьте. После этого испытайте автономное открытие и сохранение на вымышленных данных.

Проверка не заменяет резервную копию. Перед работой проверьте открытие, сохранение и восстановление на своём устройстве; установка PWA и совместимость оборудования ещё требуют проверки.

ابدأ هنا

ثلاث خطوات للإعداد. يمكنك استخدام المتصفح مباشرة؛ إضافة أيقونة للشاشة الرئيسية اختيارية.

01 · Windows x64

الاستخدام المحلي على الكمبيوتر

فك ضغط حزمة Windows المحمولة ثم انقر مرتين على Start-WardNote.cmd. لا يلزم تثبيت بيئة التشغيل. احتفظ بالمجلد؛ إغلاق اللوحة لا يوقف الخدمة.

Start-WardNote.cmd

تعمل برامج التشغيل والإيقاف من المجلد؛ لا تستطيع صفحة المساعدة تشغيلها.

02 · HTTPS

الهواتف والأجهزة اللوحية

اطلب من المسؤول إعداد عنوان HTTPS موثوق ثم افتحه في متصفح الهاتف. عنوان localhost على الكمبيوتر لا يتيح الوصول من الهاتف.

يفتح الرابط التطبيق فقط ولا ينقل الحسابات أو كلمات المرور أو بيانات المرضى. استعد نسخة احتياطية مشفرة ومتحققاً منها على الجهاز أو العنوان الجديد؛ تطابق أسماء الحسابات لا يزامنها.

03 · PWA

اختر طريقة الفتح

iPhone / iPad: افتح في Safari، ثم مشاركة ← إضافة إلى الشاشة الرئيسية ← إضافة. أبقِ «فتح كتطبيق ويب» مفعلاً إذا ظهر.

Chrome على Android: افتح القائمة ⋮ ثم «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إن توفر، واتبع الإرشادات.

Chrome / Edge على الكمبيوتر: اختر «تثبيت» من شريط العنوان أو قائمة المتصفح إن توفر.

إذا لم يظهر زر تثبيت، تابع في المتصفح واحفظ العنوان في المفضلة. تعتمد خيارات التثبيت على المتصفح.

تحقق من الإعداد دون اتصال

ابقَ متصلاً أثناء الإعداد الأول وانتظر موارد التطبيق، ثم أعد الفتح والفحص. بعد النجاح اختبر الفتح والحفظ دون اتصال ببيانات تجريبية.

نجاح الفحص ليس نسخة احتياطية. تحقق من الفتح والحفظ والاستعادة على جهازك قبل الاستخدام الفعلي؛ ما زال تثبيت PWA وتوافق الأجهزة بحاجة للتحقق.

معالج إعداد المسؤول · HTTPS / Windows

यहाँ से शुरू करें

तीन चरणों में तैयारी करें। ब्राउज़र में सीधे उपयोग कर सकते हैं; होम स्क्रीन आइकन जोड़ना वैकल्पिक है।

01 · Windows x64

कंप्यूटर पर स्थानीय उपयोग

Windows पोर्टेबल पैकेज निकालें और Start-WardNote.cmd पर दो बार क्लिक करें। रनटाइम इंस्टॉल नहीं करना है। फ़ोल्डर रखें; पैनल बंद करने से सेवा बंद नहीं होती।

Start-WardNote.cmd

शुरू और बंद करने के प्रोग्राम फ़ोल्डर से चलते हैं; सहायता पृष्ठ इन्हें नहीं चला सकता।

02 · HTTPS

फ़ोन और टैबलेट

व्यवस्थापक से विश्वसनीय HTTPS पता तैयार करवाएँ, फिर फ़ोन ब्राउज़र में खोलें। कंप्यूटर का localhost पता फ़ोन से नहीं खुलता।

लिंक केवल ऐप खोलता है। यह खाते, पासवर्ड या रोगी डेटा नहीं भेजता। नए डिवाइस या पते पर सत्यापित एन्क्रिप्टेड बैकअप बहाल करें; समान खाता नाम अपने आप सिंक नहीं होते।

03 · PWA

खोलने का तरीका चुनें

iPhone / iPad: Safari में खोलें, साझा करें → होम स्क्रीन पर जोड़ें → जोड़ें चुनें। यदि दिखे तो वेब ऐप के रूप में खोलें चालू रखें।

Android Chrome: ⋮ मेन्यू → होम स्क्रीन पर जोड़ें या ऐप इंस्टॉल करें, यदि उपलब्ध हो, और निर्देश मानें।

कंप्यूटर Chrome / Edge: पता बार या ब्राउज़र मेन्यू में इंस्टॉल करें चुनें, यदि उपलब्ध हो।

इंस्टॉल बटन न हो तो ब्राउज़र में जारी रखें और पता बुकमार्क करें। इंस्टॉल विकल्प ब्राउज़र पर निर्भर हैं।

ऑफ़लाइन तैयारी जाँचें

पहली तैयारी में ऑनलाइन रहें, ऐप संसाधनों की प्रतीक्षा करें, फिर दोबारा खोलकर जाँचें। सफल होने पर काल्पनिक डेटा से ऑफ़लाइन खोलना और सहेजना जाँचें।

जाँच सफल होना बैकअप नहीं है। वास्तविक उपयोग से पहले अपने डिवाइस पर खोलना, सहेजना और बहाली जाँचें; वास्तविक PWA इंस्टॉल और हार्डवेयर संगतता अभी जाँचना बाकी है।

व्यवस्थापक सेटअप सहायक · HTTPS / Windows
