循记临床 WardNote — Android 0.1.2-preview

发布材料 r1 / Release material r1：交付候选目录 Android-offline-preview-0.1.2-release-ready；源码包 wardnote-android-0.1.2-preview-source-r1.zip。APK 与原 0.1.2 包字节一致，原目录保留。本轮仅准备，不实际发布。
The candidate folder is Android-offline-preview-0.1.2-release-ready, with source archive wardnote-android-0.1.2-preview-source-r1.zip. The APK is byte-identical to the retained 0.1.2 installer. This round prepares material without publishing.

1. 将 wardnote-android-0.1.2-preview.apk 复制到 Android 手机上（USB 或其他可信方式）。
2. 打开 APK，按系统提示允许本次安装来源。安装完成后可关闭“安装未知应用”权限。
3. 打开 WardNote，选择语言、个人或机构模式，创建账号和密码。程序已内置，可首次脱机启动；无需部署 HTTPS 网站。
4. 先用虚构病例验证。选择患者后，在“备忘”点击“开始录音”：确认患者，调用手机已有录音应用，返回后再次确认导入。若手机不支持直接返回，请使用“导入录音”。
5. 在设置中导出加密备份，选本机文件夹，保留 .wnmanifest 清单及所有 .wnpart 文件；完成后重新选择全套文件进行核验。

录音原件可能仍由手机录音应用保留或同步；本应用不自动删除外部原件。当前版本没有语音转文字或云同步。
卸载或清除应用数据会删除本机资料。更新时先核验备份，再安装相同签名的更新；不要先卸载。
系统最低 Android 8，且需具备所要求的 WebView 安全存储能力。真实手机、录音应用返回及临床使用尚未验证。

English quick start
1. Copy the APK to your Android phone through a trusted channel and install it.
2. Open WardNote, choose a language/account mode, and create an account and password. Bundled assets support first-use offline operation; no HTTPS website is needed.
3. Use synthetic cases first. Start recording from Memos, confirm the patient, record in the phone's recorder app, then return and confirm import. Use Import recording if the recorder cannot return a file.
4. Export an encrypted backup to a local folder. Keep the .wnmanifest file and every .wnpart file, and verify the complete set.
The recorder may retain or sync its own copy. WardNote does not delete the original. No speech recognition or cloud sync is provided in this preview.
Uninstalling or clearing app data deletes local records. Verify a backup before installing a same-signature update; do not uninstall first.
Physical-phone, OEM recorder and clinical validation remain pending. See docs/VALIDATION.md and docs/ANDROID-USER-GUIDE.md for details.

0.1.2 更新说明 / Update notes
新包沿用 0.1.0/0.1.1 应用标识与签名。更新前结束外部录音、回到应用确认导入，保存所有记录，导出并核验完整备份，再覆盖安装新包；不要卸载或清除数据。外部安装器和系统进程终止无法由应用阻止。
The update retains the 0.1.0/0.1.1 application ID and signing certificate. Finish external recording and confirm import, save records, export and verify a complete backup, then install over the existing app. Do not uninstall or clear data. The app cannot block an external installer or OS process termination.

安全修复说明：文件操作期间请等待完成；若提示未能确认清理，请检查目的文件夹并重新核验备份。
Security update: wait for file operations to finish. If cleanup cannot be confirmed, inspect the destination and reverify the backup.
