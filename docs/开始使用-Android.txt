中文快速开始
1. 在手机浏览器下载 APK，或在电脑下载后通过 USB 等可信方式传入手机。最低 Android 8.0，System WebView 还须具备所需安全及存储能力；尚未验证全部型号兼容性。
2. 打开 APK，按正常系统提示为本次可信安装来源临时允许“安装未知应用”；安装完成后可关闭该权限。遇到系统保护限制时记录错误，不绕过安全警告。
3. 打开 WardNote，选择语言、个人或机构模式，创建账号与密码。首次启动可保持飞行模式；无需部署 HTTPS 网站。先用虚构病例检查保存、退出重开、录音返回及备份恢复。
4. 选定患者后，在“备忘”点击“开始录音”，核对患者及录音安排；手机现有录音应用录完返回后，确认导入并回听。没有返回文件时使用“导入录音”。
5. 在设置中导出加密备份，保留 .wnmanifest 清单及同组所有 .wnpart 文件，重新选择完整文件组进行核验。相同账号名不会同步浏览器/PWA与Android资料。
6. 更新前完成录音导入、保存记录并核验独立备份，再以同应用标识及签名的 APK 覆盖安装。不要先卸载或清除数据。

English quick start
1. Download the APK in a phone browser, or transfer it from a computer by USB or another trusted method. Minimum Android is 8.0; WebView must also provide the required security/storage capabilities. Compatibility across all models is unvalidated.
2. Open the APK and follow normal system prompts, temporarily allowing Install unknown apps for the trusted source used for this installation. Disable it afterwards if desired. Record system-protection errors rather than bypassing security warnings.
3. Choose a language and personal/institutional mode, then create a local account/password. First launch can remain in airplane mode; no HTTPS server deployment is required. Begin with synthetic cases to check saving, reopening, recorder return and backup/restore.
4. In Memos for the intended patient, select Start recording and review the patient/recording arrangement. Use the phone's recorder, then confirm import and listen back. Use Import recording if no file is returned.
5. Export encrypted backups, keep the .wnmanifest and all matching .wnpart files, and verify the complete set. Matching usernames do not synchronize browser/PWA and Android records.
6. Before an update, finish imports, save work and verify an independent backup, then install over the existing app using the same application ID and signing identity. Do not uninstall or clear data first.

系统录音工具/文件提供程序可能另存或同步原件；WardNote 不自动删除外部原件。当前没有语音识别或云同步。
External recorders/providers may retain or synchronize originals. WardNote does not delete them. Speech recognition and cloud sync are not included.

当前为技术预览，真机、厂商录音兼容性及临床验证仍待后续反馈。
